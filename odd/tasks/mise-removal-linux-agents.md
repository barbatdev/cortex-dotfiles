# Mise removal on Linux agents

Migrate agent-dev and agent-gentle from mise-managed toolchains to native installs, then remove mise completely. agent-refactoria is unreachable (SSH timeout) and stays out of scope.

## Specs

- S1: All tools currently managed by mise must work natively after migration, at the same or compatible versions (user choice: same versions mise pins today; pacman-current acceptable on Arch for versioned system packages).
- S2: `claude`, `codex`, `opencode`, `pi` must keep working on agent-gentle through the whole migration (they run via mise shims today).
- S3: `gs sync` must pass on each migrated machine afterwards.
- S4: mise binary, `~/.local/share/mise`, `~/.config/mise` and shell references removed after verification.
- S5: agent-refactoria: report blocked, do not attempt.
- S6: Method: system package manager (apt on Ubuntu / pacman on Arch) + official installers/tarballs + npm -g for npm-distributed AI CLIs.

## Tasks

- T1 (S1,S6): agent-dev — native installs (go 1.27.1 tarball, node 24 LTS NodeSource, python3 system, starship, bun), rewrite ~/.bashrc PATH refs.
- T2 (S1,S3): agent-dev — verify go/node/pnpm/gs sync; then remove mise (S4).
- T3 (S1,S2,S6): agent-gentle — native installs (pacman go/gh/node, npm -g claude/codex/opencode/pi/pnpm, bun/uv official), fix fish configs.
- T4 (S2,S3): agent-gentle — verify all AI clients + gs sync; then remove mise (S4).
- T5 (S5): agent-refactoria — report blocked, pending SSH access.
