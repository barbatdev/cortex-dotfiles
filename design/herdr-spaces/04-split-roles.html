Role split

Spaces navigation

  • Where I am: accent bar + raised row on the current space
  • Where I jump: name + ⌘1–9 key
  • Git: branch, ↑ahead ↓behind, ✎dirty
  • Machine groups with online state
  • No pills, no task line, no spinner
  • Quiet small-caps label · count · +

Agents activity

  • What happens: state pills, task, progress
  • What needs me: question + Answer first
  • Idle timeline · calm block when quiet
  • Darker tray (#0B0714) docked under the sidebar, rounded top, grip + edge
  • Own bold header with a live summary: needs you · running · idle

Accessibility

  • Dot: role=img with aria-label and a title tooltip; the space button's name also says the state (“…, Gentle Shell working, This computer”).
  • Same info as text: every dotted space has a matching card or row in Agents with a worded pill or “New” badge.
  • Contrast: all text AA; dots ≥ 5.48:1 on every row background; grey meta switches to #C7A6FF on raised rows.
  • Landmarks: Spaces is a <nav>, Agents a labelled <section> — screen readers hear two distinct regions.
